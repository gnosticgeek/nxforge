# Play in a window

Starts the game in a window, which holds a steady 60 in matches on a ProMotion Mac. Make the window as large as you like.

A window presents on the display link, which put every frame on time in Tom's matches (2026-11-19), where full screen dipped to
57-59 fps. Use this if Steady 60 in full screen is not enough. It overrides the settings window's Display mode while on.

```env
DM_FULLSCREEN=0
```
